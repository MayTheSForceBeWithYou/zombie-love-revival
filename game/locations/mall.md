# Mall — The Undead Remember

*Seed: Scenario 3 — The Undead Remember.*

## Description

A reclaimed mall turned community workshop, where survivors and Rememberers rebuild — and where recovered objects spark memories in the dead who once owned them.

## Mood

Busy, hopeful, full of the smell of sawdust and second chances.

## Gameplay Purpose

Hub for the memory-recovery loop using found objects; introduces the gift gently.

## Important NPCs / Encounters

- A Rememberer relearning their old trade
- An Archivist cataloguing recovered objects

## Possible Events

- Returning an object triggers a Rememberer's first flicker
- An Archivist pushes to recover a dangerous memory

## Visual / Audio Notes

Power-tool hum, a radio playing half-remembered songs, skylight sun on dust.
