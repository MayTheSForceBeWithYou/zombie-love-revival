# Hospital — The Undead Remember

*Seed: Scenario 3 — The Undead Remember.*

## Description

The old hospital holds the densest, hardest memories — and the records that might explain the night of the Fall.

## Mood

Quiet, weighty, charged with truths better left sleeping.

## Gameplay Purpose

Mystery site; recovering high-stakes memories that advance the outbreak investigation.

## Important NPCs / Encounters

- A Rememberer whose recovered memories implicate someone
- Sable, who remembers this place all too well

## Possible Events

- Recovering a memory that names a cause of the Fall
- Sable nearly breaks under a shared recollection

## Visual / Audio Notes

Faint heart-monitor echoes, fluttering paper records, cool blue light.
