# Event 002 — The Price of a Name — The Cure Was Love

*Seed: Scenario 1 — The Cure Was Love.*

## Event Summary

A revival demands a real cost; the player loses a specific memory and realizes the gift is eroding them.

## Trigger Condition

Mid Act II, after two successful revivals.

## Characters Involved

- Player
- Sable or Riley (route-dependent)
- Crow

## Player Choice

- Pay the memory to complete the revival
- Abort and let the Stilled remain frozen

## Consequences

- A named memory is permanently removed and shown to the player
- Romance partner reacts to the player's self-erasure
- Sets up the Act III stakes

## Sample Scene Beats

- The revival succeeds; the saved soul weeps and thanks them
- The player reaches for a memory and finds a blank
- Their partner: 'What did that just cost you?'
- Crow quietly records the lost memory so it isn't gone entirely
