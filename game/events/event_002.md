# Event 002 — A Memory That Bites — The Undead Remember

*Seed: Scenario 3 — The Undead Remember.*

## Event Summary

A recovered memory turns out to be traumatic, harming the Rememberer and revealing a hard truth about the Fall.

## Trigger Condition

Mid Act II, the hospital.

## Characters Involved

- Player
- Sable
- A Rememberer
- An Archivist

## Player Choice

- Recover the full, painful memory for the truth
- Stop to protect the Rememberer
- Let only the player see it, sparing the Rememberer

## Consequences

- Advances the outbreak mystery
- Affects a Rememberer's stability and trust
- Sable reveals she remembers more than she's said

## Sample Scene Beats

- The memory surfaces wrong — fear, then a name
- The Rememberer recoils; the room goes cold
- Sable, quietly: 'I was there. I've been carrying this.'
- The player weighs truth against kindness
