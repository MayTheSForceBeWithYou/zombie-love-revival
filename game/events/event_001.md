# Event 001 — The First Flicker — The Undead Remember

*Seed: Scenario 3 — The Undead Remember.*

## Event Summary

Returning a lost object to a blank zombie sparks their first recovered memory, revealing the player's gift.

## Trigger Condition

Start of Act I, the mall workshop.

## Characters Involved

- Player
- A blank-turned-Rememberer
- Crow

## Player Choice

- Help recover the memory fully
- Stop partway, fearing the cost
- Let an Archivist guide the recovery instead

## Consequences

- Unlocks the memory-recovery loop
- Establishes the Rememberer community
- Crow begins guiding which memories are safe

## Sample Scene Beats

- The player presses an old object into still hands
- The zombie's eyes flicker; a single true memory surfaces
- A name returns; the first name goes on the wall
- Crow: 'Gently. Some doors open inward.'
